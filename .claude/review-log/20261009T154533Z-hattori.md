### M1. `Galaxy Explorer.cmd`: os dois loops de espera nao tem saida
`:waitdocker` repete para sempre se o Docker Desktop nao estiver no caminho fixo, falhar ao iniciar
ou se o `docker` nao estiver no PATH. `:waitapp` repete para sempre se o backend/frontend nunca
ficar healthy (crash, porta ocupada). Em qualquer desses casos o usuario ve so "Aguardando..." sem
nenhum diagnostico. Correcao: contador com limite e mensagem.
```bat
set /a TRIES=0
:waitapp
curl.exe -s -o nul -f "%URL%" >nul 2>&1
if not errorlevel 1 goto appok
set /a TRIES+=1
if %TRIES% geq 100 (
  echo A aplicacao nao respondeu em 5 min. Veja: docker compose ps / docker compose logs backend
  pause
  exit /b 1
)
timeout /t 3 /nobreak >nul
goto waitapp
:appok
```
(Mesmo padrao em `:waitdocker`, com uns 40 x 3 s, e `if not exist "...Docker Desktop.exe"` antes do `start`.)
Os labels estao fora dos blocos `if` e o `goto` de dentro do bloco esta correto; o problema e so a falta de limite.
