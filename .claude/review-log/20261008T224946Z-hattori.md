### M1 — Recorte hips2fits: falta o titular da licença e `rights_text` não é um texto de direitos
`ingestion/images/CutoutIngestion.java:418-427` (`candidate`), `connector/hips2fits/HipsPropertiesParser.java:40-50`,
`HipsSurveyMetadata`, `V8 hips_survey_snapshot`.

As duas fixtures reais trazem `hips_copyright = CNRS/Unistra`, o titular da
licença `hips_license = ODbL-1.0` do HiPS (é diferente de `obs_copyright`, que
é o crédito dos dados: "PS1 Science Consortium" / "Digitized Sky Survey -
STScI/NASA..."). O parser descarta `hips_copyright`, então o recorte fica com
licença ODbL e sem o licenciante — no PanSTARRS o crédito não cita o CDS em
lugar nenhum (só o `acknowledgment` genérico da tabela `source`). Além disso,
`rightsText` e `licenseCode` recebem o mesmo valor (`m.hipsLicense()`), então
`rights_text` = "ODbL-1.0" duplica o código e não diz de quem são os direitos.
Isso viola a regra central (proveniência completa, licença + origem). Não é
metadado inventado, mas está incompleto.

Correção:
```java
// HipsSurveyMetadata: + String hipsCopyright (pode ser null)
new HipsSurveyMetadata(survey.hipsId(), required(props, "obs_title", survey),
        required(props, "obs_copyright", survey), blankToNull(props.get("obs_copyright_url")),
        required(props, "hips_license", survey), blankToNull(props.get("hips_copyright")),
        blankToNull(props.get("bib_reference")), creatorDid);

// CutoutIngestion.candidate: rights_text = declaração literal, não o código
String rights = m.hipsCopyright() == null ? "hips_license = " + m.hipsLicense()
        : "HiPS © " + m.hipsCopyright() + ", hips_license = " + m.hipsLicense();
```
Inclua também uma coluna `hips_copyright` em `hips_survey_snapshot`, numa
migração V9 (o V8 ainda não foi commitado, então dá pra corrigir no próprio V8
antes do primeiro commit, sem violar a regra "nunca alterar V1–V7").
