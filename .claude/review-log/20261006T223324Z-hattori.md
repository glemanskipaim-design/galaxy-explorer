## MAJOR

### N1. A retenção usa `records_ok = 0` como sinal de "nenhum payload referenciado", e isso não vale para run interrompido
`RawPayloadRepository.deleteForUnproductiveOnDemandRunsBefore` (33-41) apaga os `raw_payload` de runs
`on_demand` com `records_ok = 0`. O problema é que `IngestionRunRepository.failDangling` (usado em
`ImportJobService.recoverInterrupted`) fecha runs que estavam em `running` sem mexer em `records_ok`, que
fica em 0. Como cada objeto é gravado na sua própria transação, um run que caiu depois de gravar o objeto
deixa `measurement.raw_payload_id` apontando para esses payloads.

Passados 30 dias, o `DELETE` bate na FK `measurement.raw_payload_id` (que não tem `ON DELETE`). O
statement inteiro falha e o `@Scheduled` passa a falhar toda hora: a partir daí nenhum payload é mais
expurgado, e o único sinal é um erro no log do scheduler.

A causa de fundo é usar um contador como substituto da referência real, o que contraria a regra de
proveniência. Correção: checar a referência diretamente.
```sql
DELETE FROM raw_payload p
USING ingestion_run r
WHERE p.run_id = r.id AND r.trigger = 'on_demand' AND r.status <> 'running'
  AND r.finished_at < :cutoff
  AND NOT EXISTS (SELECT 1 FROM measurement m WHERE m.raw_payload_id = p.id)
```
Com o `NOT EXISTS`, o filtro `records_ok = 0` pode até sair: um payload que nenhuma medição referencia
mais, depois de um refresh, também deixa de ser proveniência de nada. Se o usuário quiser manter os
payloads de runs produtivos por auditoria, mantenha o `records_ok = 0` **junto** com o `NOT EXISTS`.

### n1. `ImportJobWorker.userMessage` (251-262) usa `switch` com `default`
É o mesmo padrão do m8 da 1a rodada, mas em código novo. `WRITE_FAILED` e qualquer `Kind` futuro caem
em "Erro interno" sem aviso do compilador. Troque por uma switch expression exaustiva:
```java
return switch (kind) {
    case SOURCE_UNAVAILABLE -> "Fonte indisponível no momento (SIMBAD/CDS); tente novamente mais tarde" + run + ".";
    case SOURCE_QUERY_FAILED -> "Falha na consulta à fonte" + run + ".";
    case SCHEMA_MISMATCH -> "O esquema da fonte mudou; importação suspensa até revisão" + run + ".";
    case REJECTED -> "Dados da fonte rejeitados na validação" + run + ".";
    case WRITE_FAILED, INTERNAL_ERROR -> "Erro interno" + run + ".";
    case WRITTEN, NOT_FOUND -> throw new IllegalArgumentException("não é falha: " + kind);
};
```
